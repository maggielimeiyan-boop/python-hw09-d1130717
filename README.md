## 4. 課後思考問題

### 問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用要以 3 人計算？直接把字串拆成列表，再轉成各自的集合，保留了什麼、失去了什麼？

- **為什麼桌遊費用以 3 人計算**：
  測試一的桌遊原始名單整理後為 `['amy', 'ben', 'amy', 'cora']`，共有 4 筆紀錄，但其中 `'amy'` 重複填寫了兩次。依活動規則，同一人在同一場活動重複報名只算一位參加者且只收一次費用，因此不重複的桌遊參加者只有 `'amy'`、`'ben'`、`'cora'` 共 **3 人**，費用應以 3 人計算（`3 × 120 = 360.00` 元）。
- **字串拆成 `list` 再轉成 `set` 的保留與失去**：
  - **保留了什麼**：把字串去掉空白、轉小寫並以逗號切分後，每個出現過的姓名都完整保留下來，且在轉成集合的過程中，**去除了同一場內的重複姓名**，方便後續做集合運算（交集、聯集、差集）與計算不重複人數。
  - **失去了什麼**：原本填寫的**先後順序**與**重複次數**都會消失（例如 `'amy'` 出現幾次、誰先填誰後填），同時集合本身沒有索引位置，若要依字母順序顯示，還需要另外用 `sorted()` 排序。

### 問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。

- **集合關係說明**：
  測試三中，桌遊去重集合為 $B = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，電影去重集合為 $M = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$。兩場去重後的名單完全相同，因此：
  - 聯集（總不重複參加者）：$B \cup M = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，人數 $|B \cup M| = 3$ 人。
  - 交集（共同參加者）：$B \cap M = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，3 位參加者同時報了兩場活動。
  - 差集：$B - M = \emptyset$（0 人）、$M - B = \emptyset$（0 人）。

  「報名人次」代表各場去重人數相加（同一人參加兩場算 2 人次），而各場費用是依該場去重人數分別計費，因此雖然不重複人數只有 3 人，但人次與總應收仍與測試一相同。

- **算式說明**：
  - **報名人次**：$|B| + |M| = 3 + 3 = 6$（人次）
  - **桌遊應收**：$|B| \times 120 = 3 \times 120 = 360$（元，即 `360.00` 元）
  - **電影應收**：$|M| \times 80 = 3 \times 80 = 240$（元，即 `240.00` 元）
  - **總應收**：$360 + 240 = 600$（元，即 `600.00` 元）
